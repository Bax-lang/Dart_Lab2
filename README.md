// Консольное ToDo-приложение на Dart (Лабораторная работа №2)

Консольное CLI-приложение для управления списком задач, написанное на языке Dart с применением принципов объектно-ориентированного программирования (ООП). Программа позволяет создавать задачи с автоматической нумерацией, просматривать их список, отмечать выполненными и удалять, а также поддерживает цветной вывод в терминал с помощью пакета `ansicolor`.

// Запуск
1. Клонировать репозиторий: `git clone https://github.com`

3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

// Ответы на вопросы

1. **В чём разница между полем класса и обычной переменной в функции?**  
   Поле класса принадлежит каждому конкретному экземпляру (объекту) класса, хранит его состояние и существует всё время, пока живёт сам объект в памяти. Обычная переменная внутри функции является локальной — она создаётся при вызове функции и уничтожается сразу после завершения её работы.

2. **Что такое конструктор и зачем он нужен?**  
   Конструктор — это специальный метод, имя которого совпадает с именем класса, автоматически вызываемый при создании нового объекта. Он нужен для начальной инициализации полей объекта и приведения его в корректное рабочее состояние (что особенно важно в Dart из-за системы null-safety).

3. **Зачем нужен `@override` перед `toString()`? Что будет если его убрать?**  
   Аннотация `@override` явно указывает компилятору, что метод переопределяет одноимённый метод родительского класса (`Object`), защищая код от случайных опечаток в названии или параметрах. Если убрать `@override`, программа продолжит работать корректно, так как сама сигнатура `String toString()` совпадает с родительской, но анализатор кода может выдать предупреждение о нарушении стиля Dart.

4. **Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?**  
   Обычное поле создаётся отдельно для каждого объекта класса, поэтому у каждой задачи свой уникальный `id` и `title`. Статическое поле (`static`) принадлежит самому классу целиком, а не отдельным его экземплярам. В программе существует ровно **одна** копия такого поля, общая для всех созданных объектов класса `Todo`.

5. **Что означает нижнее подчёркивание в `_counter`?**  
   В языке Dart символ нижнего подчёркивания (`_`) в начале имени переменной, поля или метода делает этот идентификатор приватным на уровне библиотеки (файла). Это значит, что обратиться к `_counter` можно только внутри файла `lib/todo.dart`, а из других файлов (например, `bin/lab2_todo.dart`) он недоступен напрямую.
